# TPA — Flutter version (2020–2021)

Second generation of [TPA — Travay Pam Asire](https://github.com/Miken2001/tpa-ionic), the Haitian job-matching app, rewritten in **Flutter** with **Firebase** after the Ionic version.
Two Firebase projects remain from this period:
- **Wigz** — Android app `com.tpa.wigz`, nicknamed "The second TPA's version"
- **TPA2021** — Android app `com.first.my_app`

This repository has **no code**: the source was lost (hosting expired / not recovered). It documents the project with dated evidence. Every entry in [HISTORY.md](HISTORY.md) was **written in 2026** and committed on the day the work happened, with the evidence for that date.
